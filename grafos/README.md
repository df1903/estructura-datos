# Grafos

Clases `Vertice`, `Arista` y `Grafo` (dirigido y ponderado). Enunciados: [parcial 2022](../docs/enunciados/parcial_grafos_2022.pdf) y [proyecto librerías](../docs/enunciados/proyecto_libreria_grafos.pdf).

**Taller (11 puntos):** `minMaxAristas`/`maxMinAristas`, `gradoVertices`, `verticeMayorGrado`, `promedioListaAdyacencias`, `pozos`, `fuentes`, `promedioPesoAristas`, `aristaMayorPeso`/`aristaMenorPeso`, `verticeAdyacente`, `listaAdyacencias`, `verticesNoContemplados`, `adyacenciaMasComun`.

**Algoritmos:** `recorridoAmplitud`, `recorridoProfundidad`, `dijkstra`, `floydWarshall`, `prim`, `kruskal`, `boruvka`, `bloquearArista` (solo si hay ruta alterna), `esConexo`, `tieneCiclos`, `convertirNoDirigido`, `Grafo.desdeJSON`.

Los métodos `mostrar...` imprimen; el resto devuelve datos.

```bash
python -m grafos.taller_grafos
```
