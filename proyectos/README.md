# Proyectos

- [`libreria_grafos/`](libreria_grafos/) - un mensajero recorre 10 librerías y su casita: carga desde JSON, bloqueo de caminos, BFS/DFS, Dijkstra, Prim, Kruskal, Borůvka y Floyd-Warshall.
- [`isla_cuevas/`](isla_cuevas/) - simulación de la isla "El Paro": árbol de cuevas, camiones, almacén, creación balanceada de cuevas.

```bash
python -m proyectos.libreria_grafos.main --demo
python -m proyectos.isla_cuevas.main --segundos 600 --semilla 1
```
