# Backtracking

Plantilla: elegir → llamar recursivamente → **deshacer** la elección (retroceder).

| Problema | Función |
|----------|---------|
| Permutaciones | `permutaciones(lista)` |
| Subconjuntos que suman un objetivo (con poda) | `subconjuntos_suma(numeros, objetivo)` |
| N reinas | `n_reinas(n)` |
| Camino en un laberinto | `laberinto(matriz)` |
| Coloreado de grafos | `colorear_grafo(adyacencias, colores)` |

```bash
python -m backtracking.problemas
```
